# 1. Check for Binary

**Category:** String → Easy

## Problem

Given a string **s**, the task is to check if it is a **binary string** or not. A binary string is a string which only contains the characters **'0'** and **'1'**.

**Examples:**

```
Input: s = "01010101010"
Output: true
```

```
Input: s = "geeks101"
Output: false
```
