# 5. Check for Palindrome

**Category:** String → Easy

## Problem

Given a string **s**, the task is to check if it is palindrome or not.

**Examples:**

```
Input: s = "abba"
Output: true
Explanation: s is a palindrome
```

```
Input: s = "abc"
Output: false
Explanation: s is not a palindrome
```
