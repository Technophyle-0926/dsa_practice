# 7. Add n Binary Strings

**Category:** String → Medium

## Problem

Given **n binary strings**, the task is to find their **sum** which is also a binary string.

**Examples:**

```
Input:  arr[] = ["1101", "111"]
Output: "10100"
Explanation:

Input : arr[] = ["1", "10", "11"]
Output : "110"
```
