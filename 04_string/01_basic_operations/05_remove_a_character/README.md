# 5. Remove a Character

**Category:** String → Basic Operations

## Problem

Given a string and a position (0-based indexing), remove the character at the given position.

**Examples:**

```
Input : s = "abcde",  pos = 1
Output : s = "acde"

Input : s = "a",  pos = 0
Output : s = ""
```
