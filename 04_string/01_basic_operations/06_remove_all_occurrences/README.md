# 6. Remove all occurrences

**Category:** String → Basic Operations

## Problem

Given a string and a character, remove all the occurrences of the character in the string.

**Examples:**

```
Input : s = "geeksforgeeks"
        c = 'e'
Output : s = "gksforgks"

Input : s = "geeksforgeeks"
        c = 'g'
Output : s = "eeksforeeks"

Input : s = "geeksforgeeks"
        c = 'k'
Output : s = "geesforgees"
```

## Function Signature

```dart
dynamic removeAllOccurrences(String s, String c)
```

Your solution must define this function with the same name and parameters; the leaderboard calls it.
