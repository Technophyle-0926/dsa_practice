# 1. Length of a String

**Category:** String → Basic Operations

## Problem

Given a string s**,** the task is to find the length of the string.

**Examples:**

```
Input: s = "abc"
Output:  3
```

```
Input: s = "GeeksforGeeks"
Output: 13
```

```
Input: s = ""
Output: 0
```
