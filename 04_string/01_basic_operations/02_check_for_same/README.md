# 2. Check for Same

**Category:** String → Basic Operations

## Problem

Given two strings, check if these two strings are identical(same) or not. Consider **case sensitivity.**

**Examples:**

```
Input: s1 = "abc", s2 = "abc"
Output: Yes
```

```
Input: s1 = "", s2 = ""
Output: Yes
```

```
Input: s1 = "GeeksforGeeks", s2 = "Geeks"
Output: No
```
