# 9. Generate all Substrings

**Category:** String → Basic Operations

## Problem

Given a string s, containing lowercase alphabetical characters. The task is to print all non-empty substrings of the given string.

**Examples :**

```
Input :  s = "abc"
Output :  "a", "ab", "abc", "b", "bc", "c"
```

```
Input :  s = "ab"
Output :  "a",  "ab",  "b"
```

```
Input :  s = "a"
Output :  "a"
```

List<String> generateAllSubstrings(String s)
