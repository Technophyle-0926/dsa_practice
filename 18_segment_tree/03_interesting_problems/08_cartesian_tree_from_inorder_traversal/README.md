# 8. Cartesian tree from inorder traversal

**Category:** Segment Tree → Interesting Problems

## Problem

Given an in-order traversal of a cartesian tree, the task is to build the entire tree from it.

**Examples:**

```
Input: arr[] = {1, 5, 3}
Output: 1 5 3
  5
 / \
1   3

Input: arr[] = {3, 7, 4, 8}
Output: 3 7 4 8
     8
    /
   7
  / \
 3   4
```
