# 2. Trie Delete

**Category:** Trie → Basics

## Problem

Given a Trie containing lowercase English words and a string key, delete the given key from the Trie. If the key is not present, the Trie should remain unchanged.

**Examples:**

```
Input: word[] = ["apple", "app", "apply", "bat"], key = "app"
Output: ["apple", "apply", "bat"]
Explanation: The word "app" is deleted from the Trie. The words "apple", "apply", and "bat" remain unchanged.
```

```
Input: word[] = ["cat", "car", "dog"], key = "dog"
Output: ["cat", "car"]
Explanation: The word "dog" is deleted from the Trie, while "cat" and "car" remain in the Trie.
```

```
Input: word[] = ["cat", "car"], key = "can"
Output: ["cat", "car"]
Explanation: The word "can" is not present in the Trie, so the Trie remains unchanged.
```
