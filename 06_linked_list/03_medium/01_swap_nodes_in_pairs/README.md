# 1. Swap Nodes in Pairs

**Category:** Linked List → Medium

## Problem

Given the head of a singly linked list, swap every two adjacent nodes and return the new head.

**Note:** Try to swap the nodes, not only the data.

**Examples:**

```
Input :
```

```
Output : 2 -> 1 -> 4 -> 3 -> 5
```
