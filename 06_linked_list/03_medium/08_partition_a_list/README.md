# 8. Partition a List

**Category:** Linked List → Medium

## Problem

Given a linked list and a value x, partition it such that all nodes less than x come first, then all nodes with a value equal to x, and finally nodes with a vaxlue greater than x. The original relative order of the nodes in each of the three partitions should be preserved.

**Examples:**

```
Input : 1 -> 4 -> 3 -> 2 -> 5 -> 2 -> 3, x = 3
Output: 1 -> 2 -> 2 -> 3 -> 3 -> 4 -> 5
Explanation: In the below linked list, all nodes with value less than 3 are on the left and rest of the nodes on the right by maintaining the relative order.
```

```
Input: 10 -> 4 -> 20 -> 10 -> 3, x = 3
Output: 3 -> 10 -> 4 -> 20 -> 10
```
