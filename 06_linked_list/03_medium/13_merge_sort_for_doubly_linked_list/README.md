# 13. Merge Sort for Doubly Linked List

**Category:** Linked List → Medium

## Problem

Given a doubly linked list, The task is to sort the doubly linked list in non-decreasing order using merge sort.

Examples**:**

```
Input: 10 <-> 8 <-> 4 <-> 2
Output: 2 <-> 4 <-> 8 <-> 10

Input: 5 <-> 3 <-> 2
Output: 2 <-> 3 <-> 5
```

## Function Signature

```dart
DListNode? mergeSortDoublyLinkedList(DListNode? head)
```
