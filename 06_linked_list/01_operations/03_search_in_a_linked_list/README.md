# 3. Search in a Linked List

**Category:** Linked List → Operations

## Problem

Given the head of a singly linked list and an integer key, check if the key is present in the linked list or not.

**Examples:**

```
Input: key = 5
```

```
Output: true
Explanation: 5 is present in the linked list.
```

```
Input:  key = 13
```

```
Output: true
Explanation: 13 is present in the linked list.
```

```
Input:  key = 27
```

```
Output: false
Explanation: 27 is not present in the linked list.
```
