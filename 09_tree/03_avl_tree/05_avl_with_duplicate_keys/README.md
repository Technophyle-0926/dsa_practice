## Function Signature

```dart
List<String> avlWithDuplicateKeys(List<int> keys)
```

> **Note:** Duplicates increment a per-node count instead of adding nodes; return the preorder traversal as "key(count)" strings.

Your solution must define this function with the same name and parameters; the leaderboard calls it.

**Example:** `avlWithDuplicateKeys([9, 5, 10, 5, 9, 7, 17])` → `["9(2)", "5(2)", "7(1)", "10(1)", "17(1)"]`
