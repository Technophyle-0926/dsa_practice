# 7. Power of two

**Category:** Bitwise Algorithms → Easy

## Problem

Given a positive integer **n**, check whether it is a **power of 2** or not.

**Examples:**

```
Input : n = 16
Output :  true
Explanation: 2^4 = 16
```

```
Input : n = 42
Output :  false
Explanation: 42 is not a power of 2
```

```
Input : n = 1
Output : true
Explanation: 2^0 = 1
```

## Function Signature

```dart
bool powerTwo(int n)
```
