# 1. Binary Representation

**Category:** Bitwise Algorithms → Easy

## Problem

Given an integer **n,** the task is to print the **binary representation** of the number.

**Note:** The given number will be maximum of 32 bits, so append 0's to the left if the result string is smaller than 30 length.

**Examples:**

```
Input: n = 2
Output: 00000000000000000000000000000010
```

```
Input: n = 0
Output: 00000000000000000000000000000000
```

<!-- signature:start -->
## Function Signature

```dart
String binaryRepresentation(int n)
```

> **Note:** Return a 32-character binary string padded with leading zeros.

Your solution must define this function with the same name and parameters; the leaderboard calls it.

**Example:** `binaryRepresentation(2)` → `"00000000000000000000000000000010"`
