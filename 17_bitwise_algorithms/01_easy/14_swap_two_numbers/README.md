# 14. Swap Two Numbers

**Category:** Bitwise Algorithms → Easy

## Problem

Given two numbers **a** and **b**, the task is to swap them.

**Examples:**

```
Input: a = 2, b = 3
Output: 3 2
```

```
Input: a = 20, b = 0
Output: 0 20
```

```
Input: a = 10, b = 10
Output: 10 10
```
