# 15. Longest Palindromic-Rearrangeable Substring

**Category:** Bitwise Algorithms → Hard

## Problem

Given a string **s** which only contains lowercase alphabets. Find the length of the longest substring of **s** such that the characters in it can be rearranged to form a palindrome.

**Examples:**

```
Input: s = "aabe"
Output: 3
Explanation: The substring "aab" can be rearranged to "aba" which is the longest palindrome possible for this String.
```

```
Input: s = "adbabd"
Output: 6
Explanation: The whole string "adbabd" can be rearranged to form a palindromic substring. One possible arrangement is "abddba". Thus, output length of the string is 6.
```
