# 9. Count pairs with at least one digit common

**Category:** Bitwise Algorithms → Hard

## Problem

Given an array of N numbers. Find out the number of pairs i and j such that i < j and A_i and A_j have at least one digit common (For e.g. (11, 19) have 1 digit common but (36, 48) have no digit common)

**Examples:**

```
Input: A[] = { 10, 12, 24 }
Output: 2
Explanation: Two valid pairs are (10, 12) and (12, 24) which have atleast one digit common
```
