# 6. Smallest of Three

**Category:** Bitwise Algorithms → Medium

## Problem

Given three integers **a**, **b**, and **c**, the task is to find the smallest integer **without using any comparison operators**.

**Examples:**

```
Input: a = 2, b = 5, c = 7
Output: 2
Explanation: The smallest of the 3 integers is a, which is equal to 2.
```

```
Input: a = 14, b = 13, c = 10
Output: 10
Explanation: The smallest of the 3 integers is c, which is equal to 10.
```

```
Input: a = 6, b = 1, c = 9
Output: 1
Explanation: The smallest of the 3 integers is b, which is equal to 1.
```
