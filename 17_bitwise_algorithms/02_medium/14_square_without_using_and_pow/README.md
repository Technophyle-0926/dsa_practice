# 14. Square without using *, / and pow()

**Category:** Bitwise Algorithms → Medium

## Problem

Given an integer n, calculate the square of a number without using *, / and pow().

**Examples :**

```
Input: n = 5
Output: 25

Input: 7
Output: 49

Input: n = 12
Output: 144
```

A **Simple Solution** is to repeatedly add n to result.

```dart

```

**Example:** `squareWithoutPow(5)` → `25`
