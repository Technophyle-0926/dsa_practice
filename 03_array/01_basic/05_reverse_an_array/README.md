# 5. Reverse an Array

**Category:** Array → Basic

## Problem

Given an array of integers **arr[]**, reverse the array in place.

**Examples:**

```
Input: arr[] = [1, 4, 3, 2, 6, 5]
Output:  [5, 6, 2, 3, 4, 1]
Explanation: The elements are rearranged in reverse order, so the first element becomes the last, the second becomes the second last, and so on.
```

```
Input: arr[] = [4, 5, 1, 2]
Output: [2, 1, 5, 4]
Explanation: The first element 4 moves to last position, the second element 5 moves to second last and so on.
```
