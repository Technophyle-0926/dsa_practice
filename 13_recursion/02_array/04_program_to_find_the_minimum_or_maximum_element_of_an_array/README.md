# 4. Program to find the minimum (or maximum) element of an array

**Category:** Recursion → Array

## Problem

Given an array, write functions to find the minimum and maximum elements in it.

**Examples:**

```
Input: arr[] = [1, 423, 6, 46, 34, 23, 13, 53, 4]
Output: Minimum element of array: 1
               Maximum element of array: 423
```

```
Input: arr[] = [2, 4, 6, 7, 9, 8, 3, 11]
Output: Minimum element of array: 2
               Maximum element of array: 11
```

<!-- signature:start -->
## Function Signature

```dart
List<int> minAndMax(List<int> arr)
```

> **Note:** Returns [minimum, maximum].

Your solution must define this function with the same name and parameters; the leaderboard calls it.

**Example:** `minAndMax([1, 423, 6, 46, 34, 23, 13, 53, 4])` → `[1, 423]`
