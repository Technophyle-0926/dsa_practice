# 15. Sum of natural numbers using recursion

**Category:** Recursion → Mathematical

## Problem

Given a number **n**, find the **sum** of the first n natural numbers using recursion.
**Examples:**

```
Input: n = 3
Output: 6
Explanation: 1 + 2 + 3 = 6

Input: n = 5
Output: 15
Explanation: 1 + 2 + 3 + 4 + 5 = 15
```

## Function Signature

```dart
int sumNaturalNumbersRecursion(int n)
```
