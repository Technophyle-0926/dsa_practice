# 17. Sum of digit of a number using recursion

**Category:** Recursion → Mathematical

## Problem

Given a number, we need to find sum of its digits using recursion.

**Examples:**

```
Input: 12345
Output: 15
Explanation: Sum of digits → 1 + 2 + 3 + 4 + 5 = 15
```

```
Input: 45632
Output: 20
```
