# 1. Print a pattern without using any loop

**Category:** Recursion → Mathematical

## Problem

Given a number **n**, print the following pattern without using any loop.

```
n, n-5, n-10, ..., 0, 5, 10, ..., n+5, n
```

**Examples :**

```
Input: n = 16
Output: 16, 11, 6, 1, -4, 1, 6, 11, 16
```

```
Input: n = 10
Output: 10, 5, 0, 5, 10
```

## Function Signature

```dart
List<int> printPatternWithoutAnyLoop(int n)
```

Your solution must define this function with the same name and parameters; the leaderboard calls it.
