# 14. First uppercase letter in a string (Iterative and Recursive)

**Category:** Recursion → Strings

## Problem

Given a string find its first uppercase letter
**Examples :**

```
Input : geeksforgeeKs
Output : K

Input  : geekS
Output : S
```
