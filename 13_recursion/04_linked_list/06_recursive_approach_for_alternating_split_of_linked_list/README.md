# 6. Recursive approach for alternating split of Linked List

**Category:** Recursion → Linked List

## Problem

**Examples:**

```
Input : 1 2 3 4 5 6 7
Output : 1 3 5 7
         2 4 6

Input : 1 4 5 6
Output : 1 5
         4 6
```
