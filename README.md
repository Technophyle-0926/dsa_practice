# DSA Practice (Dart)

Practising the [GeeksforGeeks DSA Tutorial](https://www.geeksforgeeks.org/dsa/dsa-tutorial-learn-data-structures-and-algorithms/) problems in Dart, in course order.

## Structure

```
<NN>_<category>/            e.g. 03_array
  README.md                 every problem in the category + progress table
  <NN>_<subcategory>/       00_basics (concepts), then basic / easy / medium / hard / topic groups
    README.md               problems in this subcategory
    <NN>_<problem>/
      README.md             problem statement, examples, GfG links, your notes
      solution.dart         your solution
```

## Run a solution

```sh
dart run 03_array/01_basic/05_reverse_an_array/solution.dart
```
