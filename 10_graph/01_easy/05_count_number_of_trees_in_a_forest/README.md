# 5. Count number of trees in a forest

**Category:** Graph → Easy

## Problem

Given n nodes of a forest (collection of trees), find the number of trees in the forest.

**Examples :**

```
Input :  edges[] = {0, 1}, {0, 2}, {3, 4}
Output : 2
Explanation : There are 2 trees
                   0       3
                  / \       \
                 1   2       4
```
