# 1. Check tor Subset

**Category:** Hashing → Easy

## Problem

Given two arrays **a[]** and **b[]** of size m and n respectively, check whether b[] is a subset of a[]. Both arrays are not sorted, and elements are distinct.

**Examples:**

```
Input: a[] = [11, 1, 13, 21, 3, 7], b[] = [11, 3, 7, 1]
Output: true
```

```
Input: a[]= [1, 2, 3, 4, 5, 6], b = [1, 2, 4]
Output: true
```

```
Input: a[] = [10, 5, 2, 23, 19], b = [19, 5, 3]
Output: false
```
