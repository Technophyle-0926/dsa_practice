# 7. Count 1’s in a sorted binary array

**Category:** Searching → Easy

## Problem

Given a binary array **arr[]** of size **n,** which is sorted in non-increasing order, count the number of 1's in it.

**Examples:**

```
Input: arr[] = [1, 1, 0, 0, 0, 0, 0]
Output: 2
Explanation: Count of 1's in the given array is 2.
```

```
Input: arr[] = [1, 1, 1, 1, 1, 1, 1]
Output: 7
Explanation: All elements in the array are 1.
```

```
Input: arr[] = [0, 0, 0, 0, 0, 0, 0]
Output: 0
Explanation: The array contains no 1s.
```
