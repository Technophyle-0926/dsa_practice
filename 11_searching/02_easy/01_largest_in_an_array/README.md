# 1. Largest in an Array

**Category:** Searching → Easy

## Problem

Given an **arr[]** of elements of **size n**, return the largest element given in the array.

**Examples:**

```
Input: arr[] = [10, 20, 4]
Output: 20
Explanation: Among 10, 20 and 4, 20 is the largest.
```

```
Input: arr[] = [20, 10, 20, 4, 100]
Output: 100
```
