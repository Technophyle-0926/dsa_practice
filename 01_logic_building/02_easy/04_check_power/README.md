# 4. Check Power

**Category:** Logic Building → Easy

## Problem

Given two positive numbers **x** and **y**, check if y is a **power** of x or not.

**Examples :**

```
Input:  x = 2, y = 8
Output: true
Explanation: 2^3 is equal to 8
```

```
Input:  x = 10, y = 1
Output: true
Explanation: 10^0 is equal to 1
```

```
Input:  x = 10, y = 1001
Output: false
```
