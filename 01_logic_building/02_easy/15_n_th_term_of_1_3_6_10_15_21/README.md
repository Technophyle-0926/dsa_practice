# 15. N-th term of 1, 3, 6, 10, 15, 21…

**Category:** Logic Building → Easy

## Problem

Given a number n, find the n-th term in the series 1, 3, 6, 10, 15, 21...

**Examples**

```
Input  3
Output 6
```

```
Input  4
Output  10
```

The given series represent triangular numbers which are sums of natural numbers.

<!-- signature:start -->
## Function Signature

```dart
int nthTriangularNumber(int n)
```

> **Note:** 1-based: n = 1 gives 1.

Your solution must define this function with the same name and parameters; the leaderboard calls it.

**Example:** `nthTriangularNumber(3)` → `6`
