# 14. Decimal to Binary

**Category:** Logic Building → Easy

## Problem

Given a non negative number **n**, the task is to convert the given number into an equivalent **binary representation**.

**Examples:**

```
Input: n = 12
Output: "1100"
Explanation: the binary representation of 12 is "1100", since 12 = 1×2^3 + 1×2^2 + 0×2^1+ 0×2^0 = 12
```

```
Input: n = 33
Output: "100001"
Explanation: the binary representation of 33 is "100001", since  1×2^5 + 0×2^4 + 0×2^3 + 0×2^2 + 0×2^1 + 1×2^0  = 33
```
