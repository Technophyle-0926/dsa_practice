# 12. Prime Factorization

**Category:** Logic Building → Medium

## Problem

Given a number **n**. Find its **unique** prime factors in **increasing order**.

**Examples:**

```
Input: n = 100
Output: [2, 5]
Explanation: Unique prime factors of 100 are 2 and 5.

Input: n = 60
Output: [2, 3, 5]
Explanation: Prime factors of 60 are 2, 2, 3, 5. Unique prime factors are 2, 3 and 5.
```

## Function Signature

```dart
List<int> primeFactorization(int n)
```
