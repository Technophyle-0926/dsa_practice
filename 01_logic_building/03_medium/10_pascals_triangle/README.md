# 10. Pascal’s Triangle

**Category:** Logic Building → Medium

## Problem

Given an **integer n**, the task is to find the **first n rows** of Pascal's triangle. Pascal's triangle is a triangular array of binomial coefficients.

## Function Signature

```dart
List<List<int>> pascalsTriangle(int n)
```

> **Note:** Return the first n rows, row i having i + 1 entries.

Your solution must define this function with the same name and parameters; the leaderboard calls it.
