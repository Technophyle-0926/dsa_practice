# 5. Swap Two Numbers

**Category:** Logic Building → Basic

## Problem

Given two numbers **a** and **b**, the task is to swap them.

**Examples:**

```
Input: a = 2, b = 3
Output: 3 2
```

```
Input: a = 20, b = 0
Output: 0 20
```

```
Input: a = 10, b = 10
Output: 10 10
```

<!-- signature:start -->
## Function Signature

```dart
List<int> swapTwoNumbers(int a, int b)
```

> **Note:** Return [a, b] after swapping.

Your solution must define this function with the same name and parameters; the leaderboard calls it.

**Example:** `swapTwoNumbers(2, 3)` → `[3, 2]`
