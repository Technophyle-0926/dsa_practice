# 7. Dice Problem

**Category:** Logic Building → Basic

## Problem

Given an integer **n** representing a face of a standard six-faced dice, find the number on the opposite face. The faces of the dice are numbered from 1 to 6.

**Examples:**

```
Input: n = 2
Output: 5
Explanation: For dice facing number 5 opposite face will have the number 2.
```

```
Input: n = 6
Output: 1
Explanation: For dice facing number 6 opposite face will have the number 1.
```
