# 19. Sort n numbers in range from 0 to n^2 – 1

**Category:** Sorting → Medium

## Problem

Given an integer array **arr[]** of size **n**, where every element lies in the range **0** to **n² − 1**, sort the array in non-decreasing order in linear time.

**Examples:**

```
Input: arr[] = [40, 12, 45, 32, 33, 1, 22]
Output: [1, 12, 22, 32, 33, 40, 45]
Explanation: The array sorted in non-decreasing order is [1, 12, 22, 32, 33, 40, 45].

Input: arr[] = [24, 12, 0, 15, 8]
Output: [0, 8, 12, 15, 24]
Explanation: The array sorted in non-decreasing order is [0, 8, 12, 15, 24].
```
